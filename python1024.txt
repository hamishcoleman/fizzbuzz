Demonstrating that there is no length that people will not go to to properly
fizz their buzz, this one implements a python-like interpreter in 1024 bytes
so that it can run the python code

See https://austinhenley.com/blog/python1024.html for more details
and https://github.com/AZHenley/python1024 for the original code source
